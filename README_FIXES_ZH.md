# 投资与财务管理系统：2026-10-17 更新

入口为 https://iafm.zhongjiehuang.com/ 。仓库、ZIP与解压目录继续使用完整名称 Investment_and_Financial_Management。

保留原有MVC，主要更新如下：

- 修复大面积背景模糊、长动画与重复事件监听造成的滚动负担；滚动本身不刷新页面或请求财务API。
- 汇率、通胀与财务报告支持美元、英镑、人民币、欧元、日元、港币、澳元、加元、瑞郎和新加坡元。报告切换币种由后端重算；显示两位小数。汇率共用每天最多更新一次的缓存。
- 恢复管理员专用通胀增删改，后端强制权限检查。日期统一15日，连续同值月份合并为区间并保留最早日期；整段编辑与删除有明确提示。
- 通胀与收支表头可切换升降序；内部转账单独显示、不计入收入支出。
- 增加平衡的复式记账分录、转账原子撤销和账户改名同步。历史配对依赖双方账户凭证；疑似记录保留原分类，账户余额不重放。
- 增加登录限流、统一失败密码校验成本、来源检查、安全响应头、Secure/HttpOnly Cookie和专用数据库权限。真实密码与API密钥不写入源码。

公开通胀历史存在明确边界：多数币种可访问十年；澳元当前月度序列从2025-04开始；美元缺少2025-10。不补造无法访问的数据。来源和导入方法见 tools/inflation/README.md。

使用Java 21运行 mvn clean package；交付部署包位于 dist/。维护脚本默认dry-run，写入前要求私有备份。配置与迁移顺序见 DEPLOYMENT_UPDATE_2026-10-17.md。
